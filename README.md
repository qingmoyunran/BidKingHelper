# 项目依赖
python >= 3.12.13

# 使用方式
## python脚本
以管理员权限运行windows cmd \ powershell，找到项目目录，运行
```
.\monitor_ram.py，
```
然后脚本挂后台就行。
可以借鉴学习竞拍之王的内存构造。

## 使用原理
脚本运行时，会自动解包网络包，获取房间号，去内存里找游戏日志。
找到的关键信息，比如游戏开始，下一轮，使用道具，游戏结束，会按照内存里的格式，以阅读友好的json串格式保存进文本文档(内存里本来就是json串)

## 使用限制
这个脚本扫描内存的时间会从2秒逐步增加。由于最开始写BidKing.exe的那位程序员不喜欢释放内存，游戏进程会越来越大。
目前测试过刚启动游戏，BidKing.exe大小300MB+，2秒找到模式串。到了6000MB大小，大概8~12秒找到模式串(都去用OCR识别啊喂)。
